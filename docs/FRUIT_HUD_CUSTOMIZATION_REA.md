## “自定义”的实际范围

编辑器 `a3.r0` 提供九组可选元素：导航图标、三块导航文字、通话文字、媒体文字、媒体标题、车道组、媒体进度组。每组可拖动位置，改变大小或文字尺寸，从七种颜色中选择，并隐藏/显示；设置写入 `SharedPreferences[data]`，HUD Presentation 在创建时加载。代码证据：`ev_9a43c96e7ce4b70d04fb9c63934b79519c55a40c3e6016d8bb32a50beaa3fff2`、`ev_ac835ce4e598c2185d030019bfe59e87fa1402e771444cacdddace6a7097bc44`、`ev_3c9539391fc152d742fb5fcae5ef67e6ae4f8025cb9ff66a475be53c1c3f3fec`、`ev_4ed97efec0b8208a02ce1df7f1c8c03692bc0c8ed84c40ab934715885456a7e8`、`ev_a00537e2deac75f00dc9554b1652b6653c3280ecd291f4ad97841b212799f6a2`。

“歌词动画”是确有其名的设置文案，编辑器保存 `key_animation`，HUD 用它控制两块媒体文字的淡出/淡入。可见代码并未把一个单独的歌词字段送入 HUD，而是媒体标题/艺人更新进入同一视图。因此，当播放 App 把逐句歌词写进标题并连续更新时，HUD 可能像歌词一样切换；目前不能据此断言水果互联具有独立歌词获取、时间轴解析或任意音乐 App 的逐句歌词能力。证据：`ev_9a43c96e7ce4b70d04fb9c63934b79519c55a40c3e6016d8bb32a50beaa3fff2`、`ev_ac835ce4e598c2185d030019bfe59e87fa1402e771444cacdddace6a7097bc44`、`ev_4b8e22544f608a8461dfb75eff163b7576a7b3a94aacbd3d023e442d3bae36e2`；资源字符串 `setting_hud_anim_message` 的中文版为“歌词动画”。

在已追踪的 HUD 布局、编辑器、原生 Java 回调和导航解析路径中，未发现单独的红绿灯状态、剩余秒数或倒计时视图。编辑器中的红、黄、绿按钮用于给选中元素上色，不能当作红绿灯信息功能。此结论限于已恢复的 APK 和可见静态路径；不等于证明所有版本及外部地图数据都不可能提供该功能。

## 对本项目的迁移判断

- 布局自定义（位置、尺寸、颜色、可见性）可用本项目自己的 HUD 视图与设置实现，数据来源不变，难度较低。
- 路线概要、媒体与通话可借用现有 iAP2 导航、NowPlaying 和 CallState 解析，但需先把目前 BYD 命名的状态从厂商输出里分离。车道指引需要补充独立的车道消息解析，并按真实 iPhone 数据验证字段。
- “歌词动画”本身只是 UI 动画，容易实现；逐句歌词需要确认实际数据源。DiPlay 的媒体标题可能承载歌词行，但不能保证所有音乐 App 都这样做。
- 红绿灯倒计时目前没有可移植的水果互联 HUD 实现或已验证的数据源。若要做，先取得合法、可靠的实时信号数据，并核验时间与路口匹配，不能靠布局迁移产生。

下一步建议用停车状态分别触发导航、车道、播放媒体、歌词变化和通话，记录水果互联 HUD 画面及本项目接收的对应状态；根据实测结果确定第一批迁移内容。

## 本项目当前实现

- 拿铁 Display 3 的 CarPlay 仪表地图维持原开关；Display 4 的 HUD 有独立开关，关闭 HUD 不会关闭仪表流。
- 拿铁 HUD 使用自己的 Android Presentation、布局模型和 CarPlay iAP2 信息，不调用比亚迪 HUD 写入接口。设置弹窗提供九组元素选择、位置预览拖动、横纵位置、宽度、文字/图标尺寸、七色、可见性及媒体标题切换动画；设置持久化并可即时更新 HUD。
- 已接入导航转向、道路、转向距离、路线距离与到达时间，媒体标题/艺人、通话状态，以及 `LaneGuidanceInfoUpdate` 中的车道方向码。车道方向目前用通用箭头近似显示，尚需拿铁真机对照水果互联的方向图标和实际消息逐项校准。
- 媒体播放进度使用本项目已有的 `CarPlayPlaybackStatus` 对 NowPlayingUpdate 的时长（媒体项字段 4）与已播放时间（播放字段 1）的解析；两个字段都存在时显示时间和进度条。字段是否随不同 iPhone 音乐 App 持续更新，仍需实车验证。
- 2026-10-15 实车复测发现：原型 HUD 只在导航/媒体等数据存在且 `CarPlayHostActivity` 前台运行时创建；设置页打开或车机切换首页时会关闭。车机 Display 4 与开关保存正常，导航开启后也能显示，故改为由应用级 `GwmHudOutput` 持有 Presentation。开关开启后立即显示等待信息，不依赖导航；设置页及 CarPlay 主页面切换不主动撤销。
- 新增“叠加原车 HUD”开关：使用透明 Presentation 窗口和透明 View 背景，只绘制 CarPlay 信息模块；关闭此开关时保留黑底覆盖模式。用户在拿铁实车确认透明叠加模式正常，导航未开启时开关可立即投屏，设置期间持续显示。
- 媒体标题可能承载歌词行，动画只作用于收到的新标题；未实现独立歌词抓取。红绿灯状态/倒计时在本 APK 的可见 HUD 路径里未得到证实，没有添加虚构的红绿灯部件。

这属于根据 REA 行为证据进行的独立重建，没有复制水果互联的 APK 代码、图片或布局文件。媒体、通话和车道内容仍需在停车状态逐项实车验证。
